## 🚚 BC TRUCK WORKS Live Companion

The **BC TRUCK WORKS Live Companion** is designed for American Truck Simulator and Euro Truck Simulator 2 players. It brings driving information, trip management, and convoy tools together in one dashboard.

**Launch the Live Companion:**

https://bc-truck-works-live-companion.vercel.app/

### Features

- 🚛 Driver dashboard and trip information
- 📡 Simulator telemetry and vehicle status
- 🎙️ AI co-driver and voice prompts
- 🧭 Navigation and trip progress
- 🩺 Truck health and driving statistics
- 📦 Dispatch and bill-of-lading tools
- 📊 Trip history, mileage, fuel, and trip time
- 👥 Convoy tools and leaderboard
- 🎥 Streaming tools
- ⚙️ Alerts and customization settings

**Note:** Live vehicle data depends on the simulator running and being correctly connected to the telemetry integration. Some features may require additional configuration.
