## 💻 Run the Website Locally

You can view and test the website on your own computer without installing additional packages.

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code or your preferred code editor.
3. Open `index.html` in a web browser.

For a more convenient development experience, you can use the **Live Server** extension in Visual Studio Code to preview changes as you work.

The current website uses HTML, CSS, and JavaScript and does not require a build process.
